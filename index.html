# ESPN and Fanatics partner access ## What is included - FanaticsTV remains a separate partnership with its existing monthly audience and asset form. - ESPN Linear Partnership has been added with: - $160,718 monthly investment - $1,928,616 full-year investment - 34.32 million full-year M18+ audience target - monthly audience reporting - cumulative integration delivery YTD - private clip and screenshot evidence - PointsBet verification before submitted figures enter live reporting ## Review the build Open `Partnership_Review_ESPN_Fanatics_Preview.html`. The preview lets the PointsBet owner switch between Fanatics and ESPN and simulate each partner's submission screen. ## Enable real partner logins 1. Run `Partnership_Review_Supabase_Access_Policies.sql` once in the existing Supabase SQL editor. 2. Deploy `Partnership_Review_ESPN_Fanatics_Live.html` as the website's main HTML file. 3. Sign in using the PointsBet owner account. 4. Select **ESPN Linear Partnership**. 5. Open **Partner access**, enter the ESPN representative's email and publish access. 6. Repeat for **FanaticsTV** using the Fanatics representative's email. 7. Each representative creates or signs into an account using the exact email assigned to their partnership. Publishing access is exclusive: assigning an email to ESPN removes any previous Fanatics assignment for that same email, and vice versa. The SQL also creates a private `pr-clips` storage bucket. Evidence is accessed through temporary signed links and remains scoped to the assigned partnership. ## ESPN submission behaviour - Audience is entered for the selected month. - Integration figures are cumulative YTD totals. - The form starts with the figures reported in ESPN's July update. - A later verified submission replaces the previous cumulative position; it is not added to it. - Overdelivery on one integration does not hide a shortfall on another. - New or corrected submissions remain pending until PointsBet verifies them. ## Submission safeguards - A month must be selected. - At least one audience figure is required. - At least one asset or integration figure is required when the package includes assets. - A data source is required. - Comments are optional. - Fanatics is explicitly instructed to enter selected-month delivery only. - ESPN is explicitly instructed to enter selected-month audience plus cumulative integration delivery YTD. - Completely blank submissions are rejected.
